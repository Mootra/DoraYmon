以下文件位于被 Git 忽略的 `docs/private/`。本机存在时按链接读取；新检出没有这些文件时，以公开文档和实际代码为基础，不推断部署或验收状态。

| 文档 | 唯一职责 |

## 更新约定

- `STATUS` 只保留当前事实和未完成事项。完成一个批次后，在完成索引增加证据链接；详细流水放归档，避免持续追加到当前入口。
- 架构、接口和配置变更同步对应公开文档；一次性审查保留日期，不把检查时刻写成永久在线状态。
- 测试通过、真实模型评阅、真实平台往返和持续运行分别记录。只有实际完成的验证才能进入对应等级。
- 私有文档、原始备份、日志、凭证和真实聊天数据不加入 Git。归档保留来源及原始副本，不把旧计划重新列为当前待办。
