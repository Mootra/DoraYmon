# 命令说明

默认命令前缀是 `/`。

| 命令 | 说明 |
| --- | --- |
| `/help` | 查看命令列表 |
| `/ping` | 返回 `pong` |
| `/status` | 查看启动时间、运行模式和数据目录 |
| `/chat 你好` | 调用 DeepSeek；默认带当前会话的有限短期上下文 |
| `/清空上下文` | 清空当前私聊或“群 + 用户”会话的短期上下文 |
| `/上下文状态` | 查看短期上下文开关、会话类型、消息数、预算和闲置过期时间 |
| `/上下文摘要` | 查看当前会话的短期摘要；没有可用摘要时退回本地节选 |
| `/知识问 [问题]` | 检索本地知识库，由 DeepSeek 依据资料回答并附来源 |
| `/知识来源 [问题]` | 只查看该问题检索到的知识块和来源路径 |
| `/知识库状态` | 查看问答开关、文档数、分块数、更新时间和索引类型 |
| `/重建知识库` | 从配置目录离线重建 SQLite FTS5 索引，仅管理员可用 |
| `/天气 南昌` | 查询天气 |
| `/今日运势` | 查看今日运势 |
| `/签到` | 每日签到 |
| `/我的签到` | 查看签到统计 |
| `/吃什么 [条件]` | 根据预算、心情、口味和用餐场景推荐一款食物 |
| `/记住口味 [口味]` | 保存用户明确提交的口味偏好 |
| `/我的口味` | 查看自己保存的口味偏好 |
| `/忘记口味 [完整口味]` | 删除一条完全相同的口味偏好 |
| `/todo` | 查看待办 |
| `/admin status` | 查看管理员状态 |

私聊中可以直接发送普通文本：明确的用餐决策表达会优先调用吃什么助手，其他内容回退到 AI 聊天。群聊中需要先 @ 机器人；@ 后的普通文本遵循相同规则，未 @ 且不是显式命令的群消息会被忽略。可以通过 `BOT_ENABLE_FOOD_NATURAL_TRIGGER=false` 关闭食物自然语言触发，显式 `/吃什么` 命令不受影响。

食物插件先按已识别的口味、标签和用餐场景筛选，再从最高分候选中随机选一款；可能连续选到同一道菜，不提供持久去重。
预算支持“20元以内”“预算20”“只有10元”等表达，优先选择整个样例价格区间都在预算内的候选；仅最低价符合时会提示可能超预算，不保证当地售价。
没有匹配候选时明确说明，不自动放宽已识别的忌口。当前只识别有限标签，不具备完整的食材、过敏原或营养数据库；保存的自由文本口味并非都能参与筛选。

短期上下文默认开启；设置 `BOT_ENABLE_CHAT_HISTORY=false` 可退回单轮问答。chat 插件会按当前私聊用户或“群 + 用户”隔离保存最近完整问答轮次；`BOT_CHAT_HISTORY_LIMIT` 控制保留和读取的消息数，`BOT_CHAT_HISTORY_MAX_CONTENT_LENGTH` 控制单条保存长度，`BOT_CHAT_CONTEXT_MAX_CHARS` 控制送入模型的历史总字符数，`BOT_CHAT_CONTEXT_SUMMARY_MAX_CHARS` 控制摘要长度，`BOT_CHAT_CONTEXT_TTL_MINUTES` 控制会话闲置多久后整体失效，`BOT_CHAT_SUMMARY_RETENTION_DAYS` 控制后台摘要保留时间。聊天历史不会自动成为长期记忆或知识库。回复单段最多 1800 字，默认最多发送 3 段，总长度超过 `BOT_REPLY_MAX_TOTAL_CHARS` 才截断。

本地知识问答默认关闭。管理员先运行 `python scripts/index_knowledge.py` 或 `/重建知识库` 建立索引，再设置 `BOT_ENABLE_RAG=true` 开启 `/知识问` 和普通聊天的可选知识增强。公共资料放在知识目录根部；群资料放在 `groups/<group_openid>/`；私人资料放在 `users/<user_openid>/`。索引只读取 UTF-8 Markdown/TXT，短期聊天历史不会自动进入知识库。
