# 命令说明

默认命令前缀是 `/`。

| 命令 | 说明 |
| --- | --- |
| `/help` | 查看命令列表 |
| `/ping` | 返回 `pong` |
| `/status` | 查看启动时间、运行模式和数据目录 |
| `/chat 你好` | 调用 DeepSeek API |
| `/天气 南昌` | 查询天气 |
| `/今日运势` | 查看今日运势 |
| `/签到` | 每日签到 |
| `/我的签到` | 查看签到统计 |
| `/吃什么 [条件]` | 根据预算、心情、口味和用餐场景推荐一款食物 |
| `/记住口味 [口味]` | 保存用户明确提交的口味偏好 |
| `/我的口味` | 查看自己保存的口味偏好 |
| `/忘记口味 [完整口味]` | 删除一条完全相同的口味偏好 |
| `/todo` | 查看待办 |
| `/admin status` | 查看管理员状态 |

私聊中可以直接发送“今晚吃什么”“外卖点什么”等自然语言，机器人会优先调用吃什么助手。群聊中需要先 @ 机器人；未 @ 的普通群消息不会触发，避免机器人主动插话。可以通过 `BOT_ENABLE_FOOD_NATURAL_TRIGGER=false` 关闭自然语言触发，显式 `/吃什么` 命令不受影响。

普通群消息不会自动调用 DeepSeek，以免刷屏和消耗额度。
