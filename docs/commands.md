# 命令说明

默认命令前缀是 `/`。

| 命令 | 说明 |
| --- | --- |
| `/help` | 查看命令列表 |
| `/ping` | 返回 `pong` |
| `/status` | 查看启动时间、运行模式、数据目录 |
| `/chat 你好` | 调用 DeepSeek API |
| `/天气 南昌` | 天气功能占位 |
| `/今日运势` | 运势功能占位 |
| `/签到` | 每日签到 |
| `/我的签到` | 查看签到统计 |
| `/todo` | 待办功能占位 |
| `/admin status` | 管理员状态命令 |

普通群消息默认不会自动调用 DeepSeek，避免刷屏和消耗额度。
