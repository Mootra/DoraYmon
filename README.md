# DoraYmon

通过 QQ 账号聊天、按需参与群聊，查询附近真实店铺；可选读取按权限隔离的本地知识。

```bash
uv sync --locked
cp .env.example .env
# 在本机填写 OneBot 地址、token、允许名单和模型配置。
uv run python -m doraymon
```

需要 Python 3.12+、[uv](https://docs.astral.sh/uv/) 和提供 OneBot v11 正向 WebSocket 的 NapCat。配置默认拒绝空名单。模型名为请求配置，不代表已验证服务端实际版本。

| 操作 | 入口 |
|---|---|
| 普通私聊、显式问答 | 直接说话、`/chat 问题` |
| 查附近店铺 | `吃什么`、`换一个`、`15元以内`、`再近点`、`换到南昌站附近`、`地图` |
| 保存、查看或删除口味 | `/记住口味 口味`、`/我的口味`、`/忘记口味 口味` |
| 每日签到、查看签到 | `/签到`、`/我的签到` |
| 清理或查看当前上下文 | `/清空上下文`、`/上下文状态` |
| 结束当前成员分支 | `/停止`、`别接话了` |
| 根据资料回答、查看资料 | `/知识问 问题`、`/知识来源 问题` |
| 本地状态与帮助 | `/ping`、`/status`、`/help` |
| 管理员全局静默 | `/静默 开`、`/静默 关` |

群聊根据 @、引用、称呼、求助和连续追问参与；首轮回复前可以连续补充，说“谢谢”“先这样”“晚安”会结束自动追问，再次求助可重新参与。仅 @ 其他成员时让开；跨群引用正文和用户私人资料不会用于群回复。地图结果只证明店名、地址和直线距离；菜单价、营业状态及步行路线须另行核实。

历史以完整问答轮次保存在本机 SQLite。仅在全部发送段返回有效消息 ID 后保存；失败或结果不明时不自动重发。默认保留最近 12 轮、闲置 12 小时，按账号、群和成员隔离。短期历史不自动转成长期记忆。显式保存的口味和签到记录同样按账号、群和成员隔离，每会话最多 20 条口味，签到按北京时间每天一条；这两类记录不随 `/清空上下文` 删除，也不从聊天中自动提取，不参与地图筛选或模型提示词。

```bash
uv run ruff check .
uv run ruff format --check .
uv run pytest
```

离线测试默认禁止外部网络，仅用合成消息、临时数据库和外部服务替身。通过这些检查不能证明真实 QQ 往返、模型表达质量或当前地图资料准确。
