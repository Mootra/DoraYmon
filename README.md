# DoraYmon

基于 MaiBot 的 QQ 伙伴，提供附近用餐工具、部署配置和聊天回放评测。聊天、人设、开口节奏、学习和记忆由 MaiBot 承担。

Python 3.13，MaiBot 固定为 1.3.15，统一 QQ 连接器固定为 1.1.8。默认访问名单为空，部署者需自行配置机器人账号、模型服务和访问范围。实现与验证范围见 [当前状态](STATUS.md)。

Windows 桌面后台提供机器人状态、启动与恢复、QQ 管理、门店搜索和采集任务。食物库可按区域、品类、标签筛选，并分别查看热门名单已匹配的门店和待复核条目。关闭窗口后进入托盘，后台服务继续由监督入口管理；QQ 未登录时仍可读取 WSL 门店库和暂停、继续公开采集。管理员命令和桌面消息操作共用身份校验、发送确认与防重复记录，当前接入不支持主动申请加好友。安装与命令见 [桌面后台](docs/runbook.md#桌面后台与管理员命令)。

在仓库检出中运行：

```bash
uv sync --locked
uv run doraymon prepare
uv run doraymon install-adapter
uv run doraymon check
```

prepare 创建独立实例，应用仓库配置并复制用餐插件；install-adapter 从官方仓库下载锁定连接器。默认访问名单为空，所有群和私聊均被拦截。机器人账号和封闭名单的填写方式、模型及高德密钥位置见 [运维说明](docs/runbook.md)。

campus_food 从本地清单按校内外和类别随机挑选 1～3 家，支持换一家、条件继承、重置和停止，同一轮排除最近推荐的店。类别支持粉面、米饭、小吃、饮品等分组；明确要求校内或校外时，只使用有对应归属标注的完整店名。聊天模型自然表达本次选择，推荐依据限于已有店名、类别和归属。

用户明确要按起点或距离查店、地图导航时使用 nearby_food。高德负责地图门店，可选商家菜单 JSON、小红书及点评只读 MCP 补充资料；每条保留出处和时间，分店待核对时明确标注。慢查询提供阶段消息，同一份地图资料结果可导出 HTML、Markdown 和 JSON。

外部 MCP 服务需自行配置并确认可用；默认留空，资料缺失会如实展示。地图地点的店名、地址和直线距离只取高德，人均与评分仅作平台参考；菜单记录不证明现价、当前营业或步行距离。配置与离线导出命令见 [用餐资料配置](docs/runbook.md#用餐资料与导出)。

本地 SQLite 资料库支持门店绑定、结构化菜品/套餐、来源和时间，以及资料版本历史。配置后先查库，缺项或超期再访问已配置来源；旧记录标记待复核。运营者导入的共享菜单与成员检索结果隔离保存，查询原文和个人起点不入库。当前只创建了独立空库，真实菜单仍待取得和核对；初始化、导入与查询见 [资料库操作](docs/runbook.md#本地资料库)。

```bash
uv run ruff check .
uv run ruff format --check .
uv run pytest
uv run python -m doraymon.replay validate
uv build --wheel --offline
```

回放场景为合成内容。默认禁止外部测试网络，WebSocket 测试仅使用本机回环；模型与高德均使用替身。离线通过不代表真实模型、地图、QQ 往返或持续运行已验收。
